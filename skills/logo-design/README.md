# logo-design

Designs modern, professional logos and brand marks as clean, scalable SVG
files in the contemporary "gradient geometric" style: simple bold shapes,
smooth gradients, rounded corners, overlap and transparency, and clever use of
negative space. Every concept is verified by rendering a PNG preview before
delivery.

## Contents

- `references/concepts.md` — concept ideation guide
- `references/svg-techniques.md` — gradient, overlap, mask, and negative-space recipes
- `references/palettes.md` — color palette choices
- `scripts/render_preview.py` — renders SVGs to PNG for inspection
  (requires `cairosvg`: `pip install cairosvg`)

## Install

```bash
npx skills add doko89/design-skills -s logo-design -g -y
```

See [SKILL.md](SKILL.md) for the full workflow and design rules.
